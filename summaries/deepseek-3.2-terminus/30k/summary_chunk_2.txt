#### B. Docker Container Deployment
**Container Architecture:**
```yaml
# Database Container
- Image: mypartsunlimitedmrp/db
- Base: mongo
- Ports: 27017, 28017
- Data: Initializes with MongoRecords.js

# Order Service Container  
- Image: mypartsunlimitedmrp/order
- Base: openjdk:8-jre
- Port: 8080
- Dependencies: Linked to db container
- Startup: Waits for MongoDB availability

# Web Container
- Image: mypartsunlimitedmrp/web  
- Base: tomcat:7-jre8
- Port: 80 (mapped to 8080)
- Deployment: WAR file in webapps/
```

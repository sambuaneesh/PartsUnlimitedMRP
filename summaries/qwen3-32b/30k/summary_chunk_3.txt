#### **3. Business Logic and Key Algorithms**
- **Order Processing (IntegrationService)**:
  ```java
  public void scheduledTask() {
      OrderMessage message = queueService.getQueueMessage();
      MrpConnectService.createNewOrder(message);
      queueService.deleteMessage(message);
  }
  ```
  - Triggers order creation in MRP for each message in the Azure queue.

- **Product Inventory Update (IntegrationService)**:
  ```java
  public void scheduledTask() {
      List<CatalogItem> items = mrpService.getCatalogItems();
      ProductMessage productMessage = new ProductMessage(items);
      QueueService.addQueueMessage(productMessage);
  }
  ```
  - Syncs MRP inventory with the website via Azure queue.

- **REST API Validation (OrderService)**:
  ```java
  public ResponseEntity addCatalogItem(CatalogItem info) {
      if (getRepository().getCatalogItem(info.getSkuNumber()) != null) {
          return ResponseEntity.status(HttpStatus.CONFLICT);
      }
      getRepository().upsertCatalogItem(info);
  }
  ```
  - Ensures no duplicate SKUs by checking existence before insert.

### Architectural Summary of Parts Unlimited MRP Codebase Chunk 1

#### Overview
The Parts Unlimited MRP application is a fictional, open-source Manufacturing Resource Planning (MRP) system. It is designed for training purposes and leverages technologies such as Linux, Java, Apache Tomcat, and MongoDB. The application consists of three primary components: a frontend web service, an order service, and an integration service. This summary captures the essential architectural information needed for microservice decomposition.

#### Components and Responsibilities

1. **Frontend Web Service**
   - **Responsibility**: Serves as the web interface for users to interact with the MRP application. It communicates with the Order Service to handle orders and other operations.
   - **Technology Stack**: Apache Tomcat, Java, HTML, CSS, JavaScript.
   - **API Endpoints**: Interacts with the Order Service via RESTful APIs.
   - **Deployment**: Built into a WAR file and deployed to Apache Tomcat.

2. **Order Service**
   - **Responsibility**: Manages order-related operations, including creating orders, managing quotes, handling shipments, and storing order-related data in MongoDB.
   - **Technology Stack**: Java, MongoDB.
   - **API Endpoints**:
     - `/catalog`: Manage catalog items.
     - `/dealers`: Manage dealer information.
     - `/orders`: Manage orders.
     - `/ping`: Health check endpoint.
     - `/quote`: Manage quotes.
     - `/shipment`: Manage shipment events.
   - **Data Models**:
     - `CatalogItem`: Represents catalog items.
     - `DealerInfo`: Represents dealer information.
     - `Delivery`: Represents delivery information.
     - `Order`: Represents order information.
     - `Quote`: Represents quote information.
     - `ShipmentRecord`: Represents shipment event information.
   - **Database Schema**: MongoDB collections (`catalog`, `dealers`, `orders`, `quotes`, `shipments`).
   - **Business Logic**: Order creation, quote management, shipment tracking, and scheduled tasks for updating product information.
   - **Deployment**: Built into a JAR file and runs as a standalone Java application.

3. **Integration Service**
   - **Responsibility**: Integrates with the Parts Unlimited Website to synchronize data and handle external interactions.
   - **Technology Stack**: Java, MongoDB.
   - **API Endpoints**: Not explicitly defined, but likely includes endpoints for data synchronization with the Parts Unlimited Website.
   - **Data Models**:
     - `CatalogItem`: Represents catalog items.
     - `DeliveryAddress`: Represents delivery addresses.
     - `Order`: Represents order information.
     - `PhoneInfo`: Represents phone information.
     - `Quote`: Represents quote information.
     - `QuoteItemInfo`: Represents quote item information.
     - `ShipmentEventInfo`: Represents shipment event information.
     - `ShipmentRecord`: Represents shipment record information.
     - `OrderItem`: Represents order items (website-specific).
     - `OrderMessage`: Represents order messages (website-specific).
     - `ProductItem`: Represents product items (website-specific).
     - `ProductMessage`: Represents product messages (website-specific).
   - **Database Schema**: MongoDB collections (`catalog`, `deliveryAddress`, `orders`, `phoneInfo`, `quotes`, `shipmentEventInfo`, `shipmentRecord`).
   - **Business Logic**: Data synchronization with the Parts Unlimited Website.
   - **Deployment**: Built into a JAR file and runs as a standalone Java application.

#### Service Dependencies and Communication Patterns

- **Frontend Web Service**:
  - **Dependency**: Order Service (RESTful API).
  - **Communication Pattern**: HTTP requests to Order Service endpoints.

- **Order Service**:
  - **Dependency**: MongoDB (data storage).
  - **Communication Pattern**: Direct database access to MongoDB collections.

- **Integration Service**:
  - **Dependency**: MongoDB (data storage).
  - **Communication Pattern**: Direct database access to MongoDB collections. Likely includes external API calls to Parts Unlimited Website.

#### Key Business Logic and Algorithms

- **Order Service**:
  - Order creation and management.
  - Quote generation and management.
  - Shipment tracking and event management.
  - Scheduled tasks for updating product information.

- **Integration Service**:
  - Data synchronization with the Parts Unlimited Website.
  - Handling external interactions and API calls to the Parts Unlimited Website.

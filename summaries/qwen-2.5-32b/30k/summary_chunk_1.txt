### Architectural Summary of Parts Unlimited MRP (Part 1)

#### Overview
The Parts Unlimited MRP (Manufacturing Resource Planning) application is a training tool based on the "Project Unicorn" from "The Phoenix Project" book. It demonstrates DevOps principles using open-source technologies such as Linux, Java, Apache, and MongoDB. The application consists of a web frontend, an order service, and an integration service.

#### Components and Responsibilities

1. **Frontend Service**
   - **Responsibility**: Runs Apache Tomcat and communicates with the Order Service.
   - **Technology**: Java, Apache Tomcat.
   - **API Endpoints**: Not explicitly defined in the provided codebase chunk but interacts with the Order Service via HTTP.

2. **Order Service**
   - **Responsibility**: Manages order-related operations (creating, updating, deleting orders).
   - **Technology**: Java, MongoDB.
   - **API Endpoints**: RESTful API endpoints for order operations.
     - `/catalog`: Catalog items.
     - `/dealer`: Dealer information.
     - `/order`: Order management.
     - `/ping`: Health check endpoint.
     - `/quote`: Quote management.
     - `/shipment`: Shipment tracking.
   - **Database Schema**: MongoDB collections.
     - `catalog`: Stores catalog items.
     - `dealers`: Stores dealer information.
     - `orders`: Stores order details.
     - `quotes`: Stores quote details.
     - `shipments`: Stores shipment details.
   - **Key Business Logic**: Order processing, quote generation, and shipment tracking.
   - **Dependencies**: MongoDB for data storage.

3. **Integration Service**
   - **Responsibility**: Integrates with the Parts Unlimited Website.
   - **Technology**: Java.
   - **Key Business Logic**: Scheduling tasks for order creation and product updates.
   - **Dependencies**: MongoDB for data storage.

#### Service Dependencies and Communication Patterns

- **Order Service ↔ Frontend Service**: HTTP REST API calls.
- **Integration Service ↔ Order Service**: Direct Java method calls or possibly messaging queues (details not fully provided).
- **Order Service ↔ MongoDB**: CRUD operations via MongoDB driver.
- **Integration Service ↔ MongoDB**: CRUD operations via MongoDB driver.

#### Key Business Logic and Algorithms

- **Order Service**: Order creation, updating, deletion, quote generation, and shipment tracking.
- **Integration Service**: Scheduled tasks for order creation (`CreateOrderProcessTask`) and product updates (`UpdateProductProcessTask`).

#### Configuration and Deployment Details

- **Build Tools**: Gradle for building Java projects.
